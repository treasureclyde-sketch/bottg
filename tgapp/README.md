# Барбер-Лиды — Telegram Mini App

Мини-приложение для Telegram: **Гайды** (скрипт звонка), **Поиск** (свайпер
барбершопов Уфы по рейтингу/отзывам из 2ГИС) и **Моя база** (лайки с
напоминанием + скрытые). Бэкенд на Python (FastAPI) + Postgres, всё на твоём
сервере 24/7. HTTPS — бесплатно через DuckDNS + Let's Encrypt, домен покупать
не нужно.

## Что приготовить заранее (5 минут)

1. **Бот.** В Telegram у @BotFather → `/newbot` → получи **токен**.
2. **2ГИС-ключ.** Зарегься на https://dev.2gis.com → создай ключ для **Каталога
   (Places/Catalog API)** → скопируй ключ. (Бесплатного тарифа хватает.)
3. **DuckDNS-домен.** Зайди на https://www.duckdns.org (вход через Google),
   придумай имя → получишь `имя.duckdns.org` и **token**. В поле «current ip»
   впиши IP своего сервера (или скрипт сделает это сам, если дашь token).

## Установка на сервере (Ubuntu/Debian)

```bash
sudo git clone https://github.com/treasureclyde-sketch/bottg.git /opt/bottg
cd /opt/bottg/tgapp
cp .env.example .env
nano .env          # вписать DOMAIN, WEBAPP_URL, BOT_TOKEN, DGIS_KEY, DUCKDNS_TOKEN
sudo bash deploy.sh
```

`deploy.sh` сам поставит Postgres, Python, nginx, выпустит HTTPS-сертификат,
запустит бэкенд и бота (с автозапуском). В конце напечатает адрес.

Готово: открываешь бота в Telegram → `/start` → кнопка **«Открыть Барбер-Лиды»**.

## Обновление после изменений в коде

```bash
cd /opt/bottg && sudo git pull
sudo systemctl restart barber-app barber-bot
```

## Как устроено

| Файл | Что делает |
|---|---|
| `static/index.html` | сам мини-апп (3 раздела), Telegram WebApp SDK |
| `app.py` | API: `/api/shops` (2ГИС), `/api/base` (Postgres), проверка подписи Telegram |
| `bot.py` | бот: кнопка входа в приложение |
| `deploy.sh` | установка + HTTPS + автозапуск |

- **Данные свайпера** берутся из 2ГИС (рейтинг, число отзывов, фото), ключ
  хранится только на сервере. Сортировка — самые рейтинговые и обсуждаемые
  вперёд. Результат кешируется на 6 часов.
- **База** (лайки/скрытые/просмотренные) хранится в Postgres по твоему
  Telegram-id — синхронизируется между устройствами автоматически.
- Пока 2ГИС-ключ не вписан, свайпер показывает демонстрационный список —
  чтобы можно было пощупать интерфейс.

## Заметки про фото 2ГИС

Поле фото в Каталоге 2ГИС отдаётся не для всех организаций. Где фото нет,
карточка показывает крупную букву на фирменном фоне. Если у тебя в ключе
включён доступ к фото — они подхватятся автоматически.
