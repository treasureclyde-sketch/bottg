# Барбер-Лиды — Telegram Mini App

Мини-приложение для Telegram: **Гайды** (скрипт звонка), **Поиск** (свайпер
барбершопов Уфы по рейтингу/отзывам) и **Моя база** (лайки с напоминанием +
скрытые).

**Никакого сервера не нужно.** Это статичная страница: данные лежат рядом в
`barbershops.json`, а твоя база (лайки/скрытые) хранится в **Telegram
CloudStorage** — синхронизируется между устройствами сама.

```
static/
  index.html        ← само приложение
  barbershops.json  ← список барбершопов (генерится из 2ГИС, см. ниже)
generate_data.py    ← обновляет barbershops.json (запускать изредка)
```

## 1. Список барбершопов (2ГИС)

Фото, рейтинг и число отзывов берутся из 2ГИС. Ключ нужен только тут, в браузер
он не попадает.

1. Получи бесплатный ключ на https://dev.2gis.com (раздел **Каталог / Places**).
2. Сгенерируй список:
   ```bash
   DGIS_KEY=твой_ключ python3 generate_data.py
   ```
   Создастся `static/barbershops.json`. Повторяй, когда захочешь обновить.

Пока файла нет — приложение показывает небольшой демо-список, чтобы можно было
потыкать.

## 2. Хостинг (бесплатно, HTTPS, без домена)

Telegram открывает мини-апп только по HTTPS. Залей папку `static/` на любой
бесплатный статик-хостинг — получишь готовый HTTPS-адрес:

- **Netlify Drop** — https://app.netlify.com/drop → перетащи папку `static/`.
- **Vercel** — `npx vercel static` (или через сайт).
- **Cloudflare Pages / Firebase Hosting / GitHub Pages** — тоже подойдут.

Скопируй выданный адрес вида `https://что-то.netlify.app`.

> Можно положить `static/` и на свой сервер, но тогда нужен HTTPS (домен +
> сертификат). Бесплатный хостинг проще и тоже работает 24/7.

## 3. Привязка к боту

1. У **@BotFather** → твой бот → **Bot Settings → Configure Mini App** (или
   `/newapp`) → вставь HTTPS-адрес из шага 2.
2. Готово: у бота появится кнопка-меню «Открыть». Можно также прислать прямую
   ссылку на мини-апп.

Бот-код писать не нужно — Telegram сам открывает приложение по этому адресу.

## Обновить список позже

```bash
DGIS_KEY=твой_ключ python3 generate_data.py   # перезапишет barbershops.json
```
И перезалей `static/` на хостинг (или `git pull` + редеплой, если на своём).
