# Личный секретарь (Telegram)

Обычный бот (Bot API), не юзербот — **отдельный номер не нужен**.

Два режима в одном боте:
- **Консьерж** — пишешь/говоришь боту напрямую, он ищет места в 2ГІС,
  смотрит фото/меню и кидает варианты с телефоном брони. Сам не бронирует.
- **Секретарь** — подключён к твоему аккаунту через Telegram Business и
  отвечает в твоих личных чатах от твоего имени, в т.ч. когда ты офлайн
  (нужен Telegram Premium).

## Что умеет сейчас (шаг 1)
- Принимает голосовые → распознаёт речь (OpenAI Whisper) → отвечает
- Тумблер автопилота: `/on` / `/off` (только для хозяина)
- Готов к Business-подключению (ответы в твоих чатах)

## Настройка

1. **Создай бота:** напиши @BotFather → `/newbot` → имя и юзернейм → скопируй **токен**.
2. **Узнай свой OWNER_ID:** напиши боту `@userinfobot`.
3. **Ключ OpenAI:** https://platform.openai.com (покрывает и мозг, и голос).
4. Скопируй `.env.example` → `.env`, впиши `TELEGRAM_BOT_TOKEN`, `OWNER_ID`, `OPENAI_API_KEY`.
5. Запусти:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

Чтобы потестить — просто напиши/наговори боту в личку.

## «Отвечает за меня» (нужен Premium)
1. У @BotFather: `/mybots` → бот → *Bot Settings* → включить **Business Mode**.
2. В своём аккаунте: *Настройки → Telegram Business → Чат-боты* → вписать юзернейм бота.
